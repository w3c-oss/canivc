# One-year roadmap (during pilot phases)

## Scope of work
The dashboard will feature test suite results related to deliverables of the W3C Verifiable Credentials Working Group and Credentials Community Group. 

### Out of scope

Test suite development; that is the purview of the Project Community (two groups).

## Technical Goals
These are to be validated with the Project Community.

* Increase traffic to the site
* Increase the number of implementations represented in the dashboard.
* Create a “feature level” view (more closely aligned with a “Can I XYZ” dashboard.
  Example features:
  * Unlinkability
  * Selective disclosure
  * Support for specific crypto-suites
* Fix UX to filter features by subsets of audiences (issuers, verifiers, holders)

## Promotional Goals

* Blog post announcing Can I VC as the first pilot of the Open Source Program
* Breakout session at TPAC 2026 on the experience of setting up the pilot
* Mention this pilot at the Internet Identity Workshop
