# Governance

Governance roles for this Project are distributed among three groups:
Owners, Supporters, and the Project Community.

## Owners
The primary responsibilities of the Owners to this Project are to manage
the Project, and maintain the foundational information:

* Statement of purpose of the Project (in the README)
* [Code contribution management](CONTRIBUTING.md)
* [Project Roadmap](ROADMAP.md)

All Core Committers are Owners. An Owner does not have to be a Core Committer.
The collective Owners determine whether an Owner is also a Core Committer. 

## Supporters
Supporters can enable the Project Community to achieve its roadmap through
qualified contributions to W3C, Inc. (donations, corporate sponsorships,
philanthropic funding, in-kind contributions, etc). If after conducting
necessary due diligence and agreed terms, W3C, Inc. accepts the contributions,
they will be allocated to support the Project Roadmap (consistent with W3C
accounting practices).

## Project Community
The Project Community provides the Contributors with guidance on the direction
of the project to help ensure that it continues to serve the broader Web community.

The Project Community for this Project is:

* [W3C Verifiable Credentials Working Group](https://www.w3.org/groups/wg/vc/)
* [Credentials Community Group](https://www.w3.org/groups/cg/credentials/)
