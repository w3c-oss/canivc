# Contributing to this repository

We welcome contributions to this project.

Contributors must agree to the [W3C Open Source Individual Contributor License
Agreement ("CLA")](https://www.w3.org/2026/07/w3c-open-source-icla.html).
Contributors who have not yet agreed to the CLA for this repo are prompted to
do so upon their first pull request. Pull requests are not merged until the
contributor's agreement has been recorded.

W3C maintains a record of who has made commitments to a W3C Open Source Program
project in the [w3c-oss/cla-commitments
repository](https://github.com/w3c-oss/cla-commitments).

## When there are multiple contributors

If you are not the sole contributor to a contribution (pull request), please
identify all contributors in the pull request comment.

To add a contributor (other than yourself, that's automatic), mark them one per line as follows:

```
+@github_username
```

If you added a contributor by mistake, you can remove them in a comment with:

```
-@github_username
```

If you are making a pull request on behalf of someone else but you had no part in designing the
feature, you can remove yourself with the above syntax.
